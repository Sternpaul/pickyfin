AI

Every film goes through three steps: 1 · Describe (an AI describes it from what it knows), 2 · Check (a second AI reviews the tags) and 3 · Look up (Exa finds real text, and an AI describes the film again from everything: the web text, both opinions, Jellyfin's genres and TMDB's keywords). Optionally, 4 · Re-check runs step 3 again on every film now and then. Status shows how far each step is. Changes on this page save on their own.

1 · Describe

Model for describing

Runs once per film, 20 films per call; a fast, cheap model is fine.

Model order

Tried from the top. Each model gets 3 tries (waiting a little between them when it's busy or failing), then the next one takes over. Turn off the ones that keep failing. The numbers count calls since the server last started.

2 · Check

Second opinion

A different model reviews every film's tags, 40 at a time, and names only what looks wrong. Much quicker than describing. Flagged films show up under Issues.

Model order

Same as for describing: from the top, 3 tries each. Best with different models than describing, so they catch different mistakes.

3 · Look up on the web

Exa key

Exa is a search engine. For each film it finds real text (Wikipedia, Letterboxd, TMDB…), and an AI describes the film again from that text together with both earlier opinions. Under one cent per film. A key comes from dashboard.exa.ai.

Look up flagged films right away

When the AI doesn't know a film, or something looks off, look it up and describe it again at once. Each film is looked up once.

Look up the whole library

Slowly works through every film, a few every few minutes: flagged films first, then lesser-known ones. With the second opinion on, a film waits until it has been checked, so all three steps happen in order.

4 · Re-check everything

How often

Every film goes through step 3 again: a fresh web lookup (new reviews, new consensus on Wikipedia, Letterboxd, IMDb…), then the step-3 model describes it again from everything collected. It keeps tags that still fit and changes only what's clearly wrong. Spread evenly over the time you choose, so each pass ends as the next begins. Films you edited or marked as checked are left alone.

TMDB

TMDB key

Optional. Adds precise keywords from The Movie Database ("heist", "time travel"), which sharpens matching. A free key comes from themoviedb.org → Settings → API.
